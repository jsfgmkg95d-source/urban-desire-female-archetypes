# 都市欲望女性原型库

`urban-desire-female-archetypes` 是一个独立、长期维护的小说创作资产库。项目面向都市男频小说的检索与调用，保存世界经典女性角色中可复用的人物机制，包括视觉辨识、身份反差、核心欲望、欲望升级、感情与婚姻博弈、秘密与信息杠杆、阶层欲望、风险升级、现代都市移植及人物杂交接口。

## 项目边界

- 本项目不是文学百科，也不以复述或复制经典作品剧情为目标。
- 事实、解释与现代都市改编必须分层记录；原著未确认的信息不得写成事实。
- 经典角色仅用于提取人物机制，原创小说不得照搬原剧情。
- 本仓库与所有现有小说仓库相互独立，尤其不得修改或写入 `jsfgmkg95d-source/classmate-wedding-novel`。
- 当前已完成 Stage 2.5 明确成年现代移植协议与 Stage 3A 首个双卡校准批次；仍禁止未经校准直接扩展十人或五百人批量。

## 目录说明

- `templates/`：人物卡、审计表和批次任务模板。
- `references/`：方法、字段与研究规则等参考资料。
- `characters/`：按来源媒介与传统分类的人物原型卡。
  - `chinese-classics/`：中国经典作品。
  - `world-classics/`：世界经典作品。
  - `mythology-and-epics/`：神话与史诗。
  - `film-and-tv/`：电影与电视剧。
  - `anime-and-manga/`：动画与漫画。
  - `games/`：游戏。
- `indexes/`：可检索索引与交叉引用。
- `data/`：结构化数据与机器可读资产。
- `batches/`：分批生产、复核与审计记录。
- `sources/`：来源清单、版本信息与引用证据。
