# 检索示例：秘密与退出

本例演示检索与比较，不新增人物卡，也不改变现有定级。分析均依据仓库现行卡片；原著事实应进一步回读来源。

## 需求

设计一个能靠信息改变谈判条件、却可能低估退出成本的现代都市冲突。先寻找“秘密如何变成权力”的不同机制。

## 召回与比较

从[秘密索引](../indexes/by-secret-method.md)和[权力索引](../indexes/by-power-method.md)召回候选，再回读 R、M、X 与 A：

| 候选 | 现有卡片中的机制解释 | 最需要检查的限制 |
|---|---|---|
| [阎婆惜 · CN-SHZ-001](../characters/chinese-classics/water-margin/CN-SHZ-001_阎婆惜.md) | 把偶得秘密打包为退出条件，误把信息价值当作安全保障 | 信息、兑现渠道与人身保护是不同资源 |
| [简·爱 · WC-JE-001](../characters/world-classics/jane-eyre/WC-JE-001_简·爱.md) | 秘密改变同意条件时，撤回参与；退出能力成为关系边界 | 卡片现有现代剧情与原作序列相近，H 层须重新审阅 |

两者都涉及秘密，但阎婆惜强调“给沉默定价”，简·爱强调“秘密使参与条件失效”。前者不能用后者的名字或职业来替代，也不能把两人的整条剧情链拼接。

## 回读路线

1. 对照[阎婆惜来源](../sources/CN-SHZ-001_sources.md)与[简·爱来源](../sources/WC-JE-001_sources.md)，确认版本范围、相关行为和未知项。
2. 检查两张卡 M 的奖励、风险与反证是否得到具体 F 事实支持。
3. 从 X 选择一个目标槽位与另一个边界槽位，记录来源 ID 和层。
4. 重做现代资源、兑现方式、阻力与代价，使至少两个剧情发动机无法映射到原作的专有情节。
5. 将设计与来源卡及全库最近邻比较；有完整链重合时继续拆换。

## 建议输出格式

```text
剧情需求：
候选 card_id 与匹配字段：
选中槽位与来源层：
事实依据与解释置信度：
明确未继承的原作专有物：
组合后出现的新矛盾：
可重复触发、升级与代价：
现实条件与尚待核验项：
最近邻差异及审阅结论：
```

完整的内容贡献应另存卡片与审阅记录；本例的空白格式仅用于工作记录。
