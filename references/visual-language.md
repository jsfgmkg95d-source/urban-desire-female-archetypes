# 都市男频视觉语言规范

V 层的目标是让人物在第一次出场时可辨认、可误读、可引发关系变化。它不是选美表，也不是色情器官目录。

## 1. 年龄门先于表达强度

- 仅 `CONFIRMED_ADULT` 可以使用直白的成年男性身体观察。
- `CONFIRMED_MINOR` 或 `UNKNOWN` 只能记录脸部、发型、服装、姿态、动作、声音、职业痕迹等非情色辨识信息。
- 年龄门未通过时，“低俗第一眼”必须写 `NOT_APPLICABLE：年龄门未通过`，不得用隐喻、透视衣着或“发育成熟”等方式绕过。
- 年龄判定方法见 `references/source-rules.md`。

## 2. 两类外貌必须分开

### 原著明确外貌

属于 `FACT`，只能准确转述原作在特定版本中明确给出的特征，并带来源定位。演员、海报模特、同人图和普遍印象不得混入。

### 现代男性视觉翻译

属于 `INTERPRETATION`。它回答“把原作证据转换成2020年代都市男频的第一眼语言，会形成什么身体和气质印象”。必须写明基于哪些 F 事实、哪些是分析性补足；不能反向声称原著如此描写。

现代移植中全新设计的外貌属于 `ADAPTATION`，不得标成上述两类之一。

## 3. 允许的直白范围

对确认成年女性，可直接写胸、腰、臀、腿、丰满、骨感、少妇感、成熟女性肉感、穿衣后的身体比例、衣料与身体轮廓的关系，以及普通成年男性第一眼最容易注意的位置。

允许直白不等于必须逐项填写。只有能形成辨识或剧情作用的部位才进入卡片。禁止把胸、腰、臀、腿机械写全。

避免：

- 细写性行为、性器官或生理反应；
- 以连续动作营造纯色情刺激；
- 没有身份、关系或风险后果的身体赞叹；
- 用“极品、尤物、完美身材”等空泛结论替代可辨识特征；
- 把所有角色归一成同一套网红比例。

## 4. 核心身体记忆点：只留 1—3 个

每个记忆点包含五项：

1. `body_focus`：胸、腰、臀、腿、整体体态、比例、姿态或其他实际焦点。
2. `direct_description`：一句直接但不过度的观察。
3. `basis_type`：`FACT_BASED_INTERPRETATION` 或 `ADAPTATION_DESIGN`。
4. `plot_functions`：从身份反差、欲望、误会、人际竞争、权力、危险、剧情推进中至少选择一个。
5. `function_explanation`：它具体改变谁的判断、选择或行动。

如果删除一个视觉点不会改变人物辨识、关系判断或剧情，就删除它。超过三个说明作者尚未找到真正签名。

## 5. 七类剧情功能

| 功能 | 合格问题 | 不合格写法 |
|---|---|---|
| 身份反差 | 身体/衣着与职业、名分、处境形成什么可见冲突？ | “她身材很好。” |
| 欲望 | 谁会被哪个可见信号吸引，这份欲望会促成什么行动？ | 只写观看快感。 |
| 误会 | 第一眼让人把她误判成什么人，事实怎样反转？ | 单纯说“很有反差”。 |
| 人际竞争 | 哪个身体或气质优势会触发比较、排斥、模仿或争夺？ | 把所有女性都写成嫉妒她。 |
| 权力 | 她是否主动管理注意力、距离、着装或场面，从而改变谈判？ | 默认美貌自动等于权力。 |
| 危险 | 哪个外表信号让别人放松警惕或错误升级冲突？ | 用“危险又迷人”作空标签。 |
| 剧情推进 | 这个特征能否成为认人、取证、暴露、误认或行动触发器？ | 与后续情节毫无连接。 |

## 6. “低俗第一眼”字段

该字段模拟普通成年男性未经修饰的第一判断，不代表作品真理或作者认同。

合格结构：

1. 一句直接身体/气质判断；
2. 一句指出这判断最可能错在哪里，或会驱动何种欲望、误会、竞争、权力和危险。

限制：

- 1—2 句，不扩展成幻想场景；
- 必须与 1—3 个核心记忆点一致；
- 不得把“容易被性化”写成角色真实意愿；
- 不得推断性经验、性可得性、道德或同意；
- 必须记录剧情功能；无功能则删掉或重写。

## 7. 防止同一张网红脸

视觉签名至少记录以下轴中的四个，且必须尊重原作或改编依据：

- `body_composition`：骨感、匀称、丰润、结实、松弛、厚重等整体构成；
- `attention_center`：第一注意中心，不强制是性征；
- `proportion_logic`：上下身、肩胯、腰线、身高感、重心；
- `posture_and_motion`：站、坐、走、停顿、占据空间的方式；
- `clothing_interaction`：衣料、剪裁、制服或生活磨损如何影响轮廓；
- `age_stage_signal`：仅描述已确认成年后的年轻、成熟、疲惫、保养或生活痕迹；
- `class_and_labor_trace`：职业、劳动、消费能力留下的可见痕迹；
- `facial_or_voice_anchor`：表情、眼神、声音或说话节奏的锚点。

“肤白、胸大、腰细、腿长、臀翘”不能作为默认组合。某项若确有来源或改编必要，仍须说明它为何只属于这个人物、服务哪个剧情功能，并通过最近邻对比。

## 8. V 层交付检查

- 年龄状态和证据已填写；
- 原著外貌与视觉翻译分区并标明陈述类型；
- 核心身体记忆点为 1—3 个；
- 每个记忆点至少服务一个剧情功能；
- “低俗第一眼”存在且没有越过年龄/同意边界；
- 去掉姓名后仍可凭视觉签名与最近邻区分；
- 没有无功能的色情堆砌。
