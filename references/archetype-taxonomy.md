# 一级剧情原型分类法

本分类法描述“人物如何把欲望变成行动和风险”，不是道德标签。每张卡必须选择一个 `primary_archetype_id`，可选最多三个次级 ID。机器 ID 以 `data/archetypes.json` 为准。

## 分类原则

1. 按持续驱动剧情的因果机制分类，不按职业、时代、外貌或好坏分类。
2. 主原型回答“删掉其他特征后，哪条机制仍最能解释她反复行动”。
3. 次级原型必须指出它改变了主机制的哪个阶段，不能只因有相似场面就添加。
4. 一次行为不等于原型；需要至少一组“匮乏—行动—奖励/代价”证据。
5. 原型归类属于 `INTERPRETATION`。支持它的原著行为事实仍留在 `F`。

## 多原型组合

- 主原型只能有一个；次级原型 `0—3` 个。
- 组合必须写成方向关系，例如：`class-mobility` 提供目标，`secret-bargaining` 提供手段，`desire-escalation` 提供升级方式。
- 不允许用多个 ID 遮盖机制链空白。
- 若两个候选无法区分，分别写出反证，暂定一个主 ID 并把置信度降为 `LOW`。
- 新增一级原型必须证明：现有 24 类无法表达其核心因果链、至少三张不同来源人物卡需要它，并同步更新本文、`data/archetypes.json` 和索引文档。
