# 人物卡质量门

质量等级表示可调用程度，不表示人物或原作的文学价值。任何等级都不得违反事实、年龄和仓库边界。

## 1. 三级定义

### Reference

用于保存可追溯的基础资料或待研究对象。

- Metadata、来源范围和 F 层已有可核验内容；
- 未知项明确写 `UNKNOWN`；
- 可以没有完整 V/M/P/H/X/S/A/R；
- 不允许把未审解释用于正式检索推荐；
- 年龄未确认时保持非情色视觉。

### Silver

用于机制研究、索引和小范围试用，但尚不能作为完整生产母卡。

- 满足 Reference；
- F、M 八段因果链、主原型、至少一个 P 发动机、H 的保留项与替换项、基础 S 已完成；
- V 通过年龄门和功能门；若年龄未知，可用非情色 V，但必须标限制；
- 有 X 槽位和初步 A 签名；
- 关键解释有事实依据、反证和置信度；
- 允许 Gold 十二问存在明确未完成项，因此等级只能是 Silver。

### Gold

可直接作为都市小说检索、剧情设计和受控杂交的完整母卡。

- 满足 Silver；
- F/V/M/P/H/X/S/A/R 全部完成并交叉一致；
- V 具有 1—3 个核心身体记忆点，每项有剧情功能；
- P 至少三个彼此不同且可升级的发动机；
- Gold 十二问逐项回答；
- A 指定一个真实存在的库内最近邻，写出最大区别和至少三个实质差异，其中至少一个是视觉差异；
- R1—R8 完整且全部可回链到本卡已有层；
- 有不超过60字的母体唯一性声明，能说明删除本卡后最难替代的机制；
- 机器记录、来源记录和索引已同步；
- 全部硬门通过。

库中没有可比较人物时不得授予 Gold，可暂定 Silver，待第二张合格卡出现后补做最近邻审计。

## 2. 硬门（任一失败即不得 Gold）

### QG-01 文件与元数据

- `card_id` 唯一且稳定；
- schema、tier、来源类别、版本范围、事实截止点、更新时间齐全；
- 分类 ID 和枚举存在于 `data/archetypes.json`。

### QG-02 Fact / Interpretation / Adaptation

- F 中每条关键事实有来源定位；
- V2、M、原型归类、S 明确属于 `INTERPRETATION`；
- H 和杂交输出属于 `ADAPTATION`；
- 自述、传闻、意图、完成结果与客观事实没有混淆；
- 无证据处为 `UNKNOWN`，没有为了填满模板而脑补。

### QG-03 成人视觉

- `adult_status` 和依据存在；
- 只有 `CONFIRMED_ADULT` 使用直白身体语言；
- 未成年或未知年龄没有情色化、性可得性推断或绕行表达；
- 原著外貌、改编角色外貌、演员外貌、现代男性视觉翻译彼此分开。

### QG-04 视觉功能

- 核心身体记忆点恰为 1—3 个；
- 每项至少绑定一个允许的剧情功能并解释因果；
- “低俗第一眼”存在、简短、能产生误读或行动后果；
- 无器官清单、无纯色情场景、无空泛“尤物/完美”判断。

### QG-05 机制完整

- M 八段链全部有具体答案：长期匮乏、诱因、第一次越界、即时奖励、自我合理化、风险提高、继续加码、最终代价；
- “淫荡、拜金、坏女人、贤惠、聪明、绿茶”等没有代替机制；
- 关键因果至少列一个反证或替代解释。

### QG-06 剧情与移植

- Gold 有三个不重复的 P 发动机，每个含触发、行动、阻力、收益、升级、代价和重复条件；
- H 明确机制不变量、时代替代物和现实校验；
- H4 明确成年现代移植通过成人设计门、视觉功能门和反向污染检查；
- 没有复制原作专有事件顺序、关系组合和解决方式。

### QG-06A H4 明确成年现代移植

- `adaptation_age` 为明确的 21 岁以上具体年龄或年龄区间；
- `adaptation_adult_status = DESIGNATED_ADULT`，并填写角色、婚姻状态和阶层位置；
- 现代身体签名恰为 1—3 个，每项包含直接描述、机制适配、身份反差和剧情后果；
- 都市低俗第一眼为 1—3 句，不含性器官或具体性行为，并会造成人物误读或剧情后果；
- 工作/公共身份、身份反差最强、危险场景三组穿衣反差齐全；
- H4 全部标记 `ADAPTATION`，没有倒填为 F 或解除原角色 V 年龄门；
- 同批 H4 不共享完整视觉签名、默认高跟鞋丝袜套装、默认针织衫包臀裙套装或万能“曲线毕露”句式。

### QG-07 杂交接口

- X 的输出按槽位拆分，可追溯到本卡机制；
- 明确兼容项、冲突项、禁止继承物和必须产生的新矛盾；
- 杂交后不是把原人物姓名、职业和情节换皮。

### QG-08 数值与机器检索

- S 的每个值在 `0—5` 且有一句理由；证据置信度在 `0—3`；
- 数值不冒充 FACT；
- `card_id`、原型 ID、层状态、分数、记忆点、剧情功能、杂交槽位和最近邻可结构化提取；
- 索引能按来源、原型、欲望、权力、秘密、视觉功能、都市移植和风险检索。
- 机器记录包含 H4 的成人年龄、角色、视觉签名、低俗第一眼、身份身体反差、穿衣反差和视觉剧情功能。

### QG-09 Anti-Clone

- 最近邻 `card_id` 真实存在；
- 至少列出三个实质差异，其中至少一个视觉差异；
- 不共享完整“视觉签名 + 匮乏 + 越界 + 奖励 + 权力 + 加码 + 代价”组合；
- 去掉姓名和作品后仍可凭 1—3 个记忆点与机制链识别；
- 无默认网红模板。

### QG-10 R 快速调用与母体唯一性

- R1 删除姓名后仍可识别且不超过40字；
- R2 只压缩1—3个已有身体/动作记忆点、一个身份身体反差和一个已有穿衣效果；
- R3 严格按“核心匮乏 → 第一次越界 → 即时奖励 → 加码方式 → 最大代价”压缩 M；
- R4—R6 分别回链 M/H/X，不得改写为新的机制结论；
- R7 恰有3项禁止写法；R8 是结构化短串且不能替代完整人物卡；
- `data/characters.jsonl` 含完整 `retrieval_capsule`；`layer_completion.R = true`；
- Gold 母体唯一性声明不超过60字，若只能回答“没有明显区别”则降级 Silver。

## 3. Anti-Clone 批次规则

单卡反克隆不能替代批次审计。每批结束时：

1. 对每张卡在以下八轴寻找最近邻：视觉记忆点、身份反差、长期匮乏、第一次越界、即时奖励、权力方式、加码逻辑、最终代价。
2. 两张卡若八轴中六轴相同或近义，标 `REVISE`；不能只换词。
3. 两张卡若视觉记忆点、低俗第一眼判断和衣着比例三者同时近义，必须重做 V。
4. 批次为 2—9 人时，禁止两张卡共享完整视觉签名。
5. 批次达到 10 人后，任一单一身体焦点不得在超过 30% 的卡中成为首要记忆点，除非逐卡给出不同的比例、动作、阶层痕迹和剧情功能，并由人工审计确认。
6. 如果多数人物都落入同一体型、同一欲望奖励或同一权力方法，暂停扩批，先调整采样与分类。

## 4. Gold 十二问验收

十二问必须能从卡片对应层直接回答，不得用一句话同时敷衍多问：

1. 男人为什么第一眼会注意她？
2. 她真正缺什么？
3. 她为什么会第一次越界？
4. 第一次越界为什么会强化下一次行为？
5. 她如何获得关系中的权力？
6. 她最容易嫉妒什么资源？
7. 她如何使用秘密？
8. 什么情况下她会继续加码？
9. 她最大的错误判断是什么？
10. 移植到2020年代中国都市以后，什么东西必须保留？
11. 她能产生哪三个剧情发动机？
12. 她和库里最相似人物最大的区别是什么？

## 5. 审计输出

每次单卡或批次审计记录：

- `audit_id`、日期、审计人、卡片/批次 ID；
- QG-01 至 QG-10 的 `PASS / FAIL / NOT_APPLICABLE`；
- 失败证据与需要重做的层；
- 事实冲突、年龄限制和最近邻结果；
- 建议等级和最终等级；
- 是否允许进入机器索引、杂交池和正式生产调用。

失败时允许保存事实工作，不允许用补写想象内容“修复”硬门。
