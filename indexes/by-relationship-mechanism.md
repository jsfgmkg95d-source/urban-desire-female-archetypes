# 按关系机制索引

| 机制轴 | `CN-JPM-001` 潘金莲 | `CN-SHZ-001` 阎婆惜 |
|---|---|---|
| 长期匮乏 | 稳定选择权与不可替代位置 | 关系退出权与独立生计 |
| 旧关系问题 | 失配并被安排；后来进入共享注意系统 | 资源仍在、注意与情感适配下降 |
| 外部关系功能 | 强烈被选中，兑现资源与身份出口 | 高频注意、共同趣味和替代关系 |
| 权力方法 | 管理可见性、距离、情绪奖励 | 控制证据、时点与逐项条件 |
| 秘密态度 | 遮掩、否认、抢先解释 | 定价、延迟交付、公开施压 |
| 加码逻辑 | 奖励成功后提高下一次证明门槛 | 将对方让步解释为继续抬价空间 |
| 失败点 | 把强烈选择当长期安全 | 把信息价值当人身安全 |
